Panduan 3 Step Insurans Motor SPM

STEP 1: Kiraan Premium Asas

  • Komprehensif:
    Kadar Tarif RM1,000 Pertama + [(Nilai Insurans - 1000) / 1000] × (RM26.00 / RM20.30)
  • Pihak Ketiga, Kebakaran & Kecurian:
    0.75 × Premium Asas Komprehensif
  • Pihak Ketiga:
    Kadar Tetap dari Jadual Tarif

STEP 2: Kiraan Diskaun NCD

NCD (RM) = (Peratus NCD / 100) × Premium Asas (Hasil Step 1)

STEP 3: Kiraan Premium Kasar

Premium Kasar (RM) = Premium Asas (Step 1) - Diskaun NCD (Step 2)

Tetapan Google Sheets (Google Apps Script)

Masukkan URL Web App Google Apps Script anda untuk menghantar rekod markah pelajar secara automatik ke Google Sheet guru.

Kod Google Apps Script (Salin ke Extensions > Apps Script dalam Sheet anda): 
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    sheet.appendRow([
      new Date(),
      data.nama,
      data.kelas,
      data.cubaan,
      data.markah,
      data.markahMaksimum,
      data.peratus + '%',
      data.gred
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({"result": "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({"result": "error", "error": err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
